# Quiz_Game

I recently built my very own interactive quiz game from scratch using HTML, CSS, and JavaScript! HTML gives the game its structure (like the questions and buttons), CSS makes it look colorful and neat, and JavaScript brings it to life by checking answers and keeping score. As a beginner, seeing all three pieces come together into a working game was such an exciting milestone
